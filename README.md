# SIT753 7.3HD DevOps Pipeline with Jenkins

This project uses a Spring Boot User CRUD application as the sample application for my SIT753 7.3HD DevOps pipeline task.

The aim of this task is to create a Jenkins CI/CD pipeline that can build, test, check code quality, scan security issues, deploy the application, create a release step, and monitor the deployed application.

## Technologies Used

- Java
- Spring Boot
- Maven
- JUnit
- Jenkins
- Docker
- Trivy
- GitHub
- Spring Boot Actuator

## Pipeline Stages

1. Build
2. Test
3. Code Quality
4. Security
5. Deployment
6. Release
7. Monitoring
